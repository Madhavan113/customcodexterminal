# Photographic studies

All imagery is bundled locally. The terminal makes no image or video network requests.

## Flight

- Reference: [Madhavan Prasanna's homepage](https://madhavanprasanna.com/).
- Source: [the homepage's video3.mp4](https://madhavanprasanna.com/video3.mp4), sampled from 86 seconds through approximately 89.9 seconds.
- Subject: birds taking flight across water. This is the user's supplied design reference.
- Treatment: sampled grayscale frames, one shared contrast curve, and an overlapping loop transition. The runtime translates the stored image luminance into ASCII.

## Transit

- Photographer: [Mario Calvo](https://unsplash.com/@mariocalvo).
- Photograph: [subway train in motion](https://unsplash.com/photos/a-long-exposure-shot-of-a-moving-subway-train-and-advertisement-posters-at-the-station-S_mEIfXRzIk).
- Source image: https://images.unsplash.com/36/fVSwTG05QIaE9FN7tLQ5_IMG_1122.jpg
- Usage: [Unsplash License](https://unsplash.com/license), verified on September 6, 2026.
- Treatment: crop, grayscale luminance sampling, and an animated ASCII presentation.

The `.nrf` luminance files, JSON metadata, and JPEG previews are generated by `scripts/prepare-media.py`. The terminal embeds only the luminance files. No model-generated imagery is used.

The 16-byte header is little endian: `NOIR` magic, u16 version, u16 width, u16 height, u16 FPS (0 for a still), and u32 frame count. Row-major grayscale bytes follow, with one byte per source pixel.
