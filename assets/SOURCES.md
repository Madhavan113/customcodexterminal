# Photographic studies

All imagery is bundled locally. The terminal makes no image or video network requests.

## Coast

- Photographer: [focal insight photography](https://unsplash.com/@focalinsight).
- Photograph: [rocky coast and sea](https://unsplash.com/photos/a-rocky-cliff-next-to-a-body-of-water-UNQf309jCvg).
- Source image: https://images.unsplash.com/photo-1668336874273-39a68485d393
- Usage: [Unsplash License](https://unsplash.com/license), verified on September 6, 2026.
- Treatment: a 1600×2399 source cropped to `(0, 1104, 1600, 2004)`, then sampled to 160×90 luminance. Runtime halftone coloring and slight drift interpret the user's lavender/yellow coastal reference.
- The native Terminal wallpaper also uses this photograph, combined with a faint mathematical dot/checker field. Rebuild it with `python3 scripts/prepare-background.py`. Its grain is deterministic and stationary.

## Design references

The user supplied a yellow/lavender halftone coastline and a lavender warped checker/dot pattern. These guide color, grain, and motion; their screenshots are not bundled. [Panamá Studio's Infusion Game graphic on Cosmos](https://www.cosmos.so/e/885336733) is an additional reference for a limited ink palette and textured image shapes. That artwork is not bundled.

The Moire scene is a deterministic interference field computed from warped checker lattices. It uses no downloaded or model-generated image.

## Flight

- Reference: [Madhavan Prasanna's homepage](https://madhavanprasanna.com/).
- Source: [the homepage's video3.mp4](https://madhavanprasanna.com/video3.mp4), sampled from 86 seconds through approximately 89.9 seconds.
- Subject: birds taking flight across water. This is the user's supplied design reference.
- Treatment: sampled grayscale frames, one shared contrast curve, and an overlapping loop transition. The runtime translates the stored image luminance into halftone or ASCII glyphs.

## Transit

- Photographer: [Mario Calvo](https://unsplash.com/@mariocalvo).
- Photograph: [subway train in motion](https://unsplash.com/photos/a-long-exposure-shot-of-a-moving-subway-train-and-advertisement-posters-at-the-station-S_mEIfXRzIk).
- Source image: https://images.unsplash.com/36/fVSwTG05QIaE9FN7tLQ5_IMG_1122.jpg
- Usage: [Unsplash License](https://unsplash.com/license), verified on September 6, 2026.
- Treatment: crop, grayscale luminance sampling, and a drifting halftone or ASCII presentation.

The `.nrf` luminance files, JSON metadata, and JPEG previews are generated by `scripts/prepare-media.py`. The terminal embeds only the luminance files. No model-generated imagery is used.

The 16-byte header is little endian: `NOIR` magic, u16 version, u16 width, u16 height, u16 FPS (0 for a still), and u32 frame count. Row-major grayscale bytes follow, with one byte per source pixel.
